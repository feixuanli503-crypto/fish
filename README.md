# 上班助手

一款简约大气的桌面端上班助手软件原型。它提供轻量浏览器入口、透明度调节、隐身隐藏、以及全局快捷键控制。

## 功能

- `Alt + 1`：快速隐藏窗口，并从任务栏移除。
- `Alt + 2`：恢复窗口显示。
- `Alt + ·`：彻底退出软件。
- 透明度滑杆：实时调整窗口透明度。
- 内容入口：抖音、小红书、小说、普通网页。
- 地址栏：输入网址或关键词，关键词会自动使用百度搜索。

## 运行

```powershell
npm install
npm start
```

## 说明

部分网站可能会限制在桌面壳内嵌入展示。如果遇到白屏或无法加载，可以使用地址栏访问移动站、搜索结果页，或后续接入更完整的浏览器窗口策略。
